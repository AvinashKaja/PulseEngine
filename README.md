# PulseEngine — Resilient Web Data Ingestion & Observability Engine

> **Acdyon Technologies Frontend Challenge Submission (Part 2: The Premium Home Page)**  
> *"Build It Like You Mean It"*

---

## ⚡ Overview

PulseEngine is a developer platform designed for extracting, processing, and monitoring web data from non-cooperative platforms (e.g. LinkedIn, Indeed, Naukri, Wellfound) without triggering CAPTCHA walls, IP bans, or silent DOM breakage.

---

## ✨ Features & Key Requirements

- 🎯 **Hero & Pitch**: Clear value proposition with immediate visual impact.
- 🧪 **Interactive Control Room Sandbox**: Live stealth strategy toggles (TLS Cipher Jitter, Canvas Noise Randomization, Semantic DOM Self-Repair) with real-time stream log simulator.
- 🎨 **Honesty Constraint Enforced**: Zero fake user counts, zero fake customer logos, zero fabricated testimonials. Real interactive product proof over hype.
- 🌓 **All-or-Nothing Dark & Light Theme**: Built-in toggle with full WCAG AA contrast compliance across all components.
- 📱 **Mobile Responsiveness**: Zero horizontal overflow at `390px` mobile width and `1440px` desktop width.
- 🕹️ **Bonus Round Easter Egg**: Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`) or header `>_ CLI` button triggers a retro Matrix developer terminal modal with secret commands!

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/AvinashKaja/PulseEngine.git
cd PulseEngine

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle
npm run build
```

## 🛠️ Stack & Tech Specs

- **Framework**: Vite + React 18 + TypeScript
- **Icons**: `lucide-react`
- **Styling**: Vanilla CSS Design Tokens, Glassmorphism, HSL Color System, Google Fonts (`Outfit`, `JetBrains Mono`)
- **Testing**: WCAG AA Contrast Audit, Responsiveness verified from 390px to 1440px+
